## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **Recipe Browser** | Look up every item's recipe with full ingredient lists |
| **Ingredient Search** | Find all recipes that use a specific ingredient |
| **Chain Planner** | Trace the full crafting chain for any item to raw resources |
| **Mod Support** | Works with vanilla and common mod recipe overhauls |
